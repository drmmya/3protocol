# VPN Panel Implementation Plan

> Execute with superpowers:executing-plans inline; user explicitly requested continuous execution without confirmation gates.

**Goal:** Deliver a Ubuntu 24.04 single-VPS installer and live three-protocol administration panel.
**Architecture:** Nginx HTTPS fronts an unprivileged stdlib Python HTTP API; a Unix socket root agent owns VPN state, configuration and accounting. Native systemd runs OpenVPN UDP/TCP, ocserv and Xray.
**Tech Stack:** Python 3.12 standard library, vanilla JS/CSS, SQLite, Nginx, systemd, OpenVPN, ocserv, Xray, tc, certbot.
**Spec:** ../../design.md

## Global Constraints
Ubuntu 24.04; listeners 1194/UDP,443/TCP,8443/TCP+UDP,4443/TCP+UDP,9443/HTTPS; no configured device caps; Asia/Dhaka accounting; no fake device counts or successful controls; no plaintext passwords in public archive.

## Review Focus
- Shared users with multiple sessions: preserve all rows and counters.
- Daemon restart/counter reset: never subtract traffic or double count.
- Unsafe names/hosts: reject before command/filesystem mutation.
- Agent outages: display stale data; do not fake healthy zero connections.
- Failed config apply: rollback and report failure; preserve working config.
